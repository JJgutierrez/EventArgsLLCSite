## 1. Commercial Positioning Statement

EventArgs LLC is a senior-led enterprise AI engineering consultancy. We help Microsoft 365 and Azure-centered organizations design and implement secure, grounded internal AI copilots, production RAG systems, AI governance, and automated developer workflows.

### Core Capabilities Offered
1. **Enterprise RAG Knowledge Copilots:** FastAPI, PostgreSQL/pgvector, hybrid retrieval, Reciprocal Rank Fusion (RRF), strict citation grounding, LangSmith evaluation.
2. **AI Governance & Security Hardening:** JWT/RBAC boundaries, prompt-injection guardrails, enterprise access controls, auditability.
3. **Custom AI Workflow & DevOps Automation:** Integrations with Azure DevOps, GitHub, and custom Model Context Protocol (MCP) servers with explicit human-in-the-loop review gates.

### Excluded Offers & Prohibited Claims
- We **do not** sell packaged multi-agent SaaS products.
- We **do not** market unverified client case study metrics (e.g. 60% triage claim).
- We **never** claim zero hallucinations, guaranteed accuracy, or literal performance promises.
